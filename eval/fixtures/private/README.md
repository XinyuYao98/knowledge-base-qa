# 私有素材目录 —— 内容不会提交到仓库

把**你自己的真实文档**复制到这个目录，用于手动验证解析效果。

## 规则

1. 这个目录下的所有文件都被 `.gitignore` 排除
2. 用完删掉，不要长期存放
3. **绝不把这里的文件移到 `../public/`**

## 为什么单独一个目录

`public/` 和 `synthetic/` 里的文件都会进开源仓库。
如果私有文件混在按格式分类的目录里（比如 `pdf/`），
一次误提交就会把简历、证件、合同推到公开网络。

按来源分目录，排除规则才能写得准确：`eval/fixtures/private/` 一行搞定。

## 适合放什么

- 你实际工作里遇到过的文档（脱敏后）
- 版式复杂、曾经让其他工具解析失败的文件
- 你想知道"这个能不能解析"的任何东西

## 不适合放什么

- 含身份证号、银行账号、完整住址的文件 —— 即使不提交，也建议先脱敏
- 客户/同事的个人信息
- 任何受保密协议约束的文件
