## 三、三个设计决策

### 决策 1：合并单元格必须展开

Excel 里 A3:A4 合并后，A4 的值是 `None`。不展开会得到：

```
第 3 行: 华东 | 林绍安 | 1280.5
第 4 行: None | 周慕云 | 960      ← 区域丢了
```

**后果**：问「华东区谁完成了多少」，第 4 行永远检索不到。

处理：按 `ws.merged_cells.ranges` 遍历，把左上角的值填满整个范围，并产出 `merged_cell` 告警。

### 决策 2：双行表头必须压平

```
行1: 区域 | 负责人 | 季度销售 |      |
行2:      |        | Q1      | Q2   |
```

压平为 `季度销售-Q1` / `季度销售-Q2`。不压平的话，字段名只有 `Q1`，
模型不知道 Q1 是什么。

**难点**：合并单元格展开后，第 1 行会变成 `季度销售 | 季度销售`（C1:D1 合并）。
所以不能只看 `None`，还要看"相邻重复值"这个合并痕迹。

### 决策 3：PPT 备注必须合并进正文

演示文稿的特点：**页面上只有关键词，解释在备注里。**

```
页面: 经营目标
备注: 2026 年 Q3 目标营收 8600 万元，毛利率不低于 32%...
```

不读备注，这份 PPT 等于没内容。所以正文与备注合并成一个块，标注 `【备注】` 前缀。

## 四、错误分类（这是「可观测」的前提）

| 错误码 | 场景 | 用户看到什么 |
|---|---|---|
| `no_text_layer` | 扫描件、纯图片 PDF | 「疑似扫描件，不支持 OCR」 |
| `empty_file` | 0 字节文件 | 「文件为空」 |
| `legacy_format` | .doc/.xls/.ppt | 「请另存为 .xlsx 后上传」 |
| `unsupported_format` | .xyz 等 | 「支持：pdf, docx, ...」 |
| `encrypted` | 加密 PDF | 「请先解除密码保护」 |
| `corrupt_file` | 文件损坏 | 「文件无法解析」 |

**关键**：`no_text_layer` 和 `corrupt_file` 在用户眼里是两回事。
前者是「文件没问题，是我们的能力边界」，后者是「文件坏了」。

## 七、过程中修掉的两个真实 bug

### bug 1：`md.py` 与 `csv.py` 漏导入 `WarnCode`

代码里调用了 `doc.warn(WarnCode.ENCODING_GUESSED, ...)`，但没导入 `WarnCode`。

**后果**：解析非 UTF-8 文件时直接 `NameError` 崩溃。

**发现方式**：ruff 的 `F821 Undefined name`。如果没有 lint，这个 bug 会一直潜伏到用户上传 GBK 文件才爆。

### bug 2：误删 `settings.PDF_SCANNED_TEXT_PER_PAGE`

我在 `pdf.py` 里写了一行 `del settings.PDF_SCANNED_TEXT_PER_PAGE`（本意是消除"未使用"告警）。

**后果**：直接删除了全局配置属性，导致后续所有解析都报 `AttributeError`。

**教训**：为了消除 lint 告警而修改全局状态，是最糟糕的修法。正确做法是删掉未使用的 `import`。
